## 1. 为什么照抄 AutoReviewCustom，而不是自己设计

| 问题 | 事实 | 依据 |
|---|---|---|
| 有自动表单组件吗？ | **没有**。`dsh-settings/README.zh.md:39` 官方承认「目前没有已发布的客户端这样做」 | 每个设置页都得手写控件 |
| 能 import `@deepseek-ai/dsh-client-ui-primitives` 吗？ | **不能**，静态 bundle 不允许 | 《踩坑录》§3.2 |
| 客户端文件是什么形态？ | 普通脚本，包在 `window.__ModuleLoader__.load({ id, factory(require) {…} })` 里，`const React = require('react')` | `AutoReviewCustom/client.js:23-28` |
| 表单怎么拿到？ | `ctx.configForms.get(ENTRY_ID)`，**ENTRY_ID 是 loader 条目 id，不是包名** | `:30-31`、`:887` |
| 怎么做条件注册？ | `ctx.configForms.whileServed([ENTRY_ID], () => ctx.slots.inject(...))` | `:889-925` |
| 怎么订阅表单？ | `hooks: { form }` → 组件拿到 `useForm(selector)` | `:900-901`、`:391` |

所以本设计**不发明新写法**，只把 AutoReviewCustom 的骨架复用到「工作区 × preset」这张表上。

## 2. 组件树与状态

```
SettingsSection（页面根，settings.section 槽位）
├── 状态区：只读展示「当前全局默认」+ 说明「未单独设置的工作区用它」
├── 仪表区：[ ] 启用本插件（enabled 开关）
├── 映射表（核心）
│   └── WorkspaceRow × N
│       ├── 工作区标题 + 路径（截断显示，title 属性给全路径）
│       ├── <select> preset 下拉
│       │   ├── <option value="">跟随全局默认</option>
│       │   ├── <option value="id">名称</option>
│       │   └── broken 的项：disabled + "（加载失败）"
│       └── 行内状态点：已自定义 / 跟随默认 / 映射失效（工作区已删除）
├── 失效映射区（仅当存在时显示）：列出配置里有、但工作区列表里没有的 id
└── 底部提示区（notice / error）
```

状态机只有四个：

| 状态 | 含义 | 页面表现 |
|---|---|---|
| `form.status !== 'ready'` | 表单未就绪 | 全部控件 disabled + 一行灰字 |
| `!form.writable` | Host 只读 | 同上，提示"当前部署不可写入" |
| `form.status === 'ready'` | 正常 | 可操作 |
| 写入中 | `mutate` 在飞 | 该行 select disabled，其余行照常 |

**不做**「保存」按钮：下拉一变就写（《踩坑录》§7.3：`disabled` 的保存键会被用户当成 bug）。

### 3.3 工具函数

```js
    /** Remote 调用返回信封 {ok,value}|{ok,error}，必须解包（《踩坑录》§4.3）。 */
    function unwrap(envelope) {
      if (envelope === null || typeof envelope !== 'object') return null
      if (typeof envelope.ok !== 'boolean') return envelope
      return envelope.ok === true ? envelope.value : null
    }

    /** 从 form snapshot 里安全取映射表。 */
    function readMap(snapshot) {
      const raw = snapshot?.value?.[MAP_FIELD]
      if (raw === null || typeof raw !== 'object' || Array.isArray(raw)) return {}
      const out = {}
      for (const [k, v] of Object.entries(raw)) {
        if (typeof v === 'string' && v !== '') out[k] = v
      }
      return out
    }
```

### 3.4 注册（`apply`，**必须同步**）

```js
    /** 注意：这是**函数声明**，不要在这里 return；返回值统一放在文件末尾（3.7）。 */
    function apply(ctx) {                            // ← 同步！不许出现 await
      ctx.effect(() => {
        const tag = document.createElement('style')
        tag.dataset.plugin = 'dsh-workspace-preset'
        tag.textContent = css
        document.head.appendChild(tag)
        return () => tag.remove()
      }, 'workspace-preset styles')

      ctx.effect(() => ctx.locale.register(LOCALE_NS, { en, zh }),
        'workspace-preset locale')

      const form = ctx.configForms.get(ENTRY_ID)

      // ⚠️ 这四个函数**必须在 apply 里建一次**，不能写在 `inject: () => ({...})` 里。
      // 原因：`inject()` 每次渲染都会重新求值，里面现写的箭头函数每次都是新引用；
      // 一旦它进了组件 `useEffect` 的依赖数组，就会「渲染 → 依赖变 → 重订阅 → 再渲染」
      // 无限循环。AutoReviewCustom 里的 setField 没踩到，是因为它没有被当依赖用。
      const readPresets = () => ctx.remote.agentPresets.list()
      const readWorkspaces = () => readWorkspacesFrom(ctx)
      const subscribeWorkspaces = (listener) => subscribeWorkspacesFrom(ctx, listener)
      const setWorkspacePreset = (wsId, presetId) =>
        presetId === ''
          ? form.mutate([{ op: 'unset', path: [MAP_FIELD, wsId] }])
          : form.mutate([{ op: 'set', path: [MAP_FIELD, wsId], value: presetId }])
      const setEnabled = (v) => form.set('enabled', v)

      ctx.effect(
        () => ctx.configForms.whileServed([ENTRY_ID], () =>
          ctx.slots.inject('settings.section', () =>
            ctx.slots.register(
              {
                name: 'settings.section',
                id: ENTRY_ID,
                order: 125,                     // 紧挨 Auto Review 的 120
                label: () => '新会话预设',
                locale: LOCALE_NS,
                // hooks 是唯一会每渲染重建的部分；其余全部是上面那几个稳定引用
                inject: () => ({
                  hooks: { form },
                  setEnabled,
                  setWorkspacePreset,
                  readPresets,
                  readWorkspaces,
                  subscribeWorkspaces,
                }),
              },
              Section,
            ),
          ),
        ),
        'workspace-preset settings page',
      )
    }
```

**四个要点，每个都对应一个真实坑：**

1. `form.set(field, value)` 内部是 `{ op:'set', path:[field] }` —— **单段路径**。
   要给 dict 的某个键赋值，必须自己 `mutate([{op:'set', path:[MAP_FIELD, wsId], …}])`。
   用 `set(MAP_FIELD, obj)` 会整块覆盖映射表（丢掉其他工作区的设置）。
2. `unset` 而不是写空串：验收要求"跟随全局默认"时该键**消失**。
3. `order: 125` 只是摆放位置，不抢内置槽位。
4. **传给组件的函数必须在 `apply` 里建一次**（见上面代码里那段 `⚠️`）。
   `inject()` 每次渲染都重新求值，在里面现写箭头函数 → 每次都是新引用 →
   一旦进 `useEffect` 依赖数组就是无限重订阅。这是我自己写这段时先写错、
   复核才揪出来的，抄的时候别省那几行。

### 3.5 工作区列表：走 Service，不走别人的 root hook

```js
    /**
     * 工作区列表。
     *
     * 用 `ctx.workspaces.list`（Client Service，公开契约）而不是去读
     * `ctx.slots` 的 root hook —— 后者是 dsh-client-ui-workspace 的所有权范围，
     * 对方卸载时会连带把我们搞挂。
     *
     * 该服务可能不存在（用户禁用了 workspace 插件），所以是**可选依赖**。
     */
    function workspacesService(ctx) {
      return ctx.get?.('workspaces') ?? ctx.workspaces ?? null
    }

    function readWorkspacesFrom(ctx) {
      const service = workspacesService(ctx)
      const snapshot = service?.list?.getSnapshot?.()
      const items = Array.isArray(snapshot?.items) ? snapshot.items : []
      return items.map((item) => ({
        workspaceId: String(item.workspaceId),
        path: typeof item.path === 'string' ? item.path : '',
        title: typeof item.title === 'string' ? item.title : '',
      }))
    }

    function subscribeWorkspacesFrom(ctx, listener) {
      const service = workspacesService(ctx)
      const subscribe = service?.list?.subscribe
      if (typeof subscribe !== 'function') return () => {}
      return subscribe.call(service.list, listener)
    }
```

`getSnapshot()` 的形状已核实为 `{ items, archivedSessionIds, pinnedSessionIds, state, phase, error }`，
`items[]` 每项是 `{ workspaceId, path, title, sessionIds, createdAt, updatedAt }`。

### 3.6 页面组件

```js
    function Section({
      useForm, setEnabled, setWorkspacePreset,
      readPresets, readWorkspaces, subscribeWorkspaces, t,
    }) {
      const snapshot = useForm((value) => value)
      const formReady = snapshot?.status === 'ready'
      const writable = formReady && snapshot.writable === true
      const enabled = snapshot?.value?.enabled !== false
      const map = readMap(snapshot)

      // ── 工作区列表：订阅 Service，卸载时退订 ────────────────────────
      // 注意 useLazy 初值必须包一层箭头函数：直接传 readWorkspaces 会让 React
      // 把它当 lazy initializer 调用——虽然本函数无参、行为正确，但读代码的人
      // 会以为这是 bug。显式包一层。
      const [workspaces, setWorkspaces] = React.useState(() => readWorkspaces())
      React.useEffect(() => {
        const sync = () => setWorkspaces(readWorkspaces())
        sync()
        return subscribeWorkspaces(sync)
      }, [subscribeWorkspaces, readWorkspaces])

      // ── preset 花名册：Remote，解包后按 order/id 排序 ───────────────
      const [presets, setPresets] = React.useState({ status: 'loading', rows: [] })
      React.useEffect(() => {
        let alive = true
        ;(async () => {
          try {
            const roster = unwrap(await readPresets())
            if (!alive) return
            if (roster === null || !Array.isArray(roster.presets)) {
              setPresets({ status: 'error', rows: [] })
              return
            }
            setPresets({ status: 'ready', rows: roster.presets })
          } catch {
            if (alive) setPresets({ status: 'error', rows: [] })
          }
        })()
        return () => { alive = false }
      }, [readPresets])

      // ── 提示条：3.5 秒自动消失，用 seq 保证连续操作重新计时 ─────────
      const [notice, setNotice] = React.useState(null)
      const seqRef = React.useRef(0)
      React.useEffect(() => {
        if (notice === null) return undefined
        const timer = setTimeout(() => setNotice(null), 3500)
        return () => clearTimeout(timer)
      }, [notice?.seq])

      const [busy, setBusy] = React.useState({})   // { [wsId]: true }

      const choose = async (workspaceId, presetId) => {
        if (!writable || busy[workspaceId]) return
        setBusy((prev) => ({ ...prev, [workspaceId]: true }))
        try {
          const ok = await setWorkspacePreset(workspaceId, presetId)
          seqRef.current += 1
          setNotice(ok
            ? { kind: 'ok', seq: seqRef.current, text: t('saved') }
            : { kind: 'error', seq: seqRef.current, text: t('saveFailed') })
        } catch (error) {
          seqRef.current += 1
          setNotice({ kind: 'error', seq: seqRef.current, text: String(error?.message ?? error) })
        } finally {
          setBusy((prev) => { const next = { ...prev }; delete next[workspaceId]; return next })
        }
      }

      // 配置里有、但工作区列表里没有的 id（工作区被删了）
      const known = new Set(workspaces.map((w) => w.workspaceId))
      const stale = Object.keys(map).filter((id) => !known.has(id))

      const globalDefault = presets.rows.find((row) => row.isDefault === true)?.id ?? ''

      return h('div', { className: 'wsp-page' },
        h('div', { className: 'wsp-title' }, t('title')),
        h('div', { className: 'wsp-hint' }, t('intro')),

        !formReady
          ? h('div', { className: 'wsp-hint' }, t('notReady'))
          : null,
        formReady && !writable
          ? h('div', { className: 'wsp-hint' }, t('readOnly'))
          : null,

        // ── 总开关 ────────────────────────────────────────────────
        h('div', { className: 'wsp-block' },
          h('label', { className: 'wsp-row', style: { gridTemplateColumns: '1fr auto' } },
            h('div', { className: 'wsp-meta' },
              h('div', { className: 'wsp-name' }, t('enable')),
              h('div', { className: 'wsp-path' }, t('enableHint'))),
            h('input', {
              type: 'checkbox',
              checked: enabled,
              disabled: !writable,
              onChange: (event) => { setEnabled(event.target.checked) },
            }))),

        // ── 映射表 ────────────────────────────────────────────────
        h('div', { className: 'wsp-block' },
          h('div', { className: 'wsp-path' },
            t('globalDefaultIs') + '：' + (globalDefault === '' ? '—' : presetName(presets.rows, globalDefault))),

          workspaces.length === 0
            ? h('div', { className: 'wsp-hint' }, t('noWorkspace'))
            : workspaces.map((ws) => {
                const picked = map[ws.workspaceId] ?? ''
                return h('div', { className: 'wsp-row', key: ws.workspaceId },
                  h('div', { className: 'wsp-meta' },
                    h('div', { className: 'wsp-name', title: ws.path },
                      ws.title === '' ? ws.path : ws.title,
                      picked === ''
                        ? h('span', { className: 'wsp-badge' }, t('follows'))
                        : h('span', { className: 'wsp-badge wsp-badge-custom' }, t('custom'))),
                    h('div', { className: 'wsp-path', title: ws.path }, ws.path)),
                  h('select', {
                    className: 'wsp-select',
                    value: picked,
                    disabled: !writable || busy[ws.workspaceId] === true
                      || presets.status !== 'ready',
                    onChange: (event) => { choose(ws.workspaceId, event.target.value) },
                  },
                    h('option', { value: '' }, t('followGlobal')),
                    ...presets.rows.map((row) => {
                      const broken = typeof row.broken === 'string'
                      return h('option', {
                        key: row.id,
                        value: row.id,
                        disabled: broken,
                      }, (row.name ?? row.id) + (broken ? ' ' + t('broken') : '')
                        + (row.id === globalDefault ? ' ' + t('globalTag') : ''))
                    })))
              }),

          // 失效映射：提示而不自动清理（自动清理等于悄悄丢用户配置）
          stale.length === 0 ? null
            : h('div', { className: 'wsp-error' },
                t('stalePrefix') + '：' + stale.join('、') + ' — ' + t('staleHint'))),

        // ── 提示 ────────────────────────────────────────────────────
        notice === null ? null
          : h('div', { className: notice.kind === 'ok' ? 'wsp-notice' : 'wsp-error' },
              notice.text))
    }

    /** preset id → 展示名（找不到就回 id，绝不显示空白）。 */
    function presetName(rows, id) {
      const row = rows.find((item) => item.id === id)
      return row?.name ?? id
    }
```

## 4. 写入路径（三条，各自的语义）

| 操作 | 调用 | 落盘结果 |
|---|---|---|
| 选某个 preset | `form.mutate([{op:'set', path:['presetByWorkspace', wsId], value: id}])` | `presetByWorkspace.<id>: <preset>` |
| 选「跟随全局默认」 | `form.mutate([{op:'unset', path:['presetByWorkspace', wsId]}])` | 该键**消失** |
| 总开关 | `form.set('enabled', bool)` | `enabled: false` |

`mutate` 的返回值是 `boolean`（Host 是否接受），**不是**抛异常；失败时内部已
`recover()` 重读镜像，页面会自动回到真实值。所以 UI 只需据返回值给提示，
不要自己回滚状态。

## 5. 必须处理的六个边界

| # | 情况 | 处理 |
|---|---|---|
| 1 | `ctx.configForms.get(ENTRY_ID)` 拿不到字段 | 整页 disabled + `notReady`。这几乎必然是**字段没加 `.volatile()`**（《踩坑录》§2.2） |
| 2 | `presets.status === 'error'` | 下拉 disabled，只显示"全局默认"一项；不要清空用户已有的映射显示 |
| 3 | preset id 在花名册里不存在 | 下拉显示成"（不可用）"但**保留原值**，等用户手动改 |
| 4 | 工作区被删除 | 归入 `stale` 列表，只提示不自动删 |
| 5 | 同一行连续快速切换 | `busy[wsId]` 期间 disabled；`mutate` 内部本来就有 revision CAS 串行化 |
| 6 | 页面开着时别处改了同一个 patch | 镜像 `subscribe` → `derive()` 自动把新值推下来；`select` 的 `value` 受控，会自动跟上 |

## 8. 还没解决的问题（留给实现阶段）

1. **`settings.section` 的 `order` 会不会撞号**：内置页面用什么 order 区间没有公开文档，
   我选了 125（Auto Review 是 120，实测可见）。装好后若顺序怪异，调这个数即可。
2. **`useForm` 的 selector 语义**只验证了「传 `(v) => v` 返回整个 snapshot」这一种用法；
   更细的选择器（如 `(v) => v.value.enabled`）没有实测，建议先用整 snapshot。
3. **工作区改名后 `title` 变了但 `workspaceId` 不变** —— 映射靠 id，所以不受影响；
   但 `stale` 列表是按 id 判断的，改名不会误报。这一点已由键的设计保证（设计方案 §4.3）。
